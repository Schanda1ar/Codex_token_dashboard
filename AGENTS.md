# Project agent guidance

## Agent skills

### Issue tracker

Track issues and specs in this repository's GitHub Issues. See `docs/agents/issue-tracker.md` before creating, updating, or triaging tickets.

### Triage labels

Use the five standard triage labels. See `docs/agents/triage-labels.md` when applying or interpreting them.

### Domain docs

Use one root `CONTEXT.md` and root `docs/adr/` for domain terms and decisions. See `docs/agents/domain.md` before exploring or changing those concepts.
